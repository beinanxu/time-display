# 时间显示器 (Time Display)

一个常驻桌面最上层的多功能时间显示器 —— **打点 / 时钟 / 定时 / 秒表** 四合一。

安静、无边框、不弹警告、不闪烁。就一块玻璃面板贴在屏幕角落，不打断你正在做的事。带一个图形化设置界面，改选项不用碰代码。

```
│  第4个 · 总计  48:31.20    │
│  3. 12:07.43  +12:07.43   │   ← 最近几个节点

│ 点一下打点 · M 打点 · C 复制 │
```

## 打点模式（主力功能）

**按一下定一个节点，大字显示"距离上一个节点过去了多久"。** 什么都不用设，第一下点击就开始计时。

- **单击面板任意位置 = 打点**（别的模式单击不做事，放心拖）
- 每打一次点，大字清零重新开始数，同时记下累计时间
- 下面列出最近的节点（`config.py` 里 `NODE_ROWS` 控制行数）
- 自动暂停检测：如果大字停着不动超过 1.5 秒，说明计时已暂停（再按空格或再打点继续）
- 按 `C` 把全部节点复制到剪贴板 —— 一份纯文本清单，粘哪都行：

```
#1   总计 0:00.00    起点
#2   总计 12:07.43   +12:07.43
#3   总计 48:31.20   +36:23.77
```

适合：两局之间隔了多久、休息了多久、上一件事做完到现在多久、跟人轮流用的每一段时长。

## 四种模式

| 模式 | 显示 | 用途 |
|---|---|---|
| **打点** | `12:07.43` 距上一节点 | 点一下定个节点，看间隔 |
| **时钟** | `21:47:03` + 日期星期 | 日常看时间 |
| **定时** | `24:59.8` 倒计时 | 番茄钟、护眼、"再玩半小时" |
| **秒表** | `3:07.42` 正计时，支持计次 | 测总时长、记录每一局 |

## 快捷键

| 按键 | 作用 |
|---|---|
| **单击面板** | **打点模式下：打点** |
| 点击顶部模式名 / `Tab` | 切换模式 |
| `空格` | 打点 / 定时 / 秒表：开始-暂停 |
| `M` | 打点：打一个点 |
| `L` | 秒表：计次 |
| `C` | 打点：复制全部节点到剪贴板 |
| `R` / `Esc` | 复位（打点模式会清空所有节点） |
| `↑` `↓` | 定时：±1 分钟（`Shift` 为 ±5 分钟） |
| 双击面板 | 临时隐藏 / 显示 |
| `Ctrl+Alt+M` | **全局**：打点（游戏里也能按） |
| `Ctrl+Alt+1` | **全局**：一键启停秒表（会自动切到秒表面板） |
| `Ctrl+Alt+2` | **全局**：一键启停定时（会自动切到定时面板） |
| `Ctrl+Alt+,` | **全局**：打开设置界面 |
| `Ctrl+Alt+A` | **全局**：循环切换模式 |
| `Ctrl+Alt+S` | **全局**：开始 / 暂停（当前模式） |
| `Ctrl+Alt+R` | **全局**：复位（当前模式） |

全局热键走 Win32 `RegisterHotKey`，所以在**别的窗口（包括游戏）里也能按** —— 打点模式最常用的就是这个 `Ctrl+Alt+M`。

## 设置界面

按 `Ctrl+Alt+,`（或者在命令行跑 `python settings.py`）打开图形设置：

- **秒表 / 定时 下面显示当前时间** —— 副标题里附上挂钟时间，例如 `00:21:26 · 秒表 · 已暂停`
- 时钟是否显示秒、日期格式
- 定时到点是否响铃 / 是否用系统语音念一句
- 定时默认分钟数、打点面板显示几个节点
- 所有全局热键的组合键

点「保存」会**直接写回 `config.py`**，改动立刻生效（热键组合键需要重启程序重新注册）。写文件前会自动存一份 `config.py.bak`，只替换等号右边的值，**文件里的注释和排版原样保留**。

比如把一个开关改成 `False`，文件里只会变成：

```python
SHOW_WALL_CLOCK = False  # 秒表 / 定时 的副标题里是否附上当前挂钟时间
```

## 运行

需要 Python 3.8+（只用标准库，`tkinter` 随 Python 自带，**无第三方依赖**）。

```bash
python app.py                          # 默认进打点模式，贴屏幕右上角
python app.py --mode clock             # 直接开时钟
python app.py --mode timer --minutes 25
python app.py --mode stopwatch
python app.py --probe                  # 自检：写出 _probe.txt
```

Windows 上双击 `启动时间显示器.bat` 可以无黑窗启动。

## 配置

全部在 [`config.py`](config.py) 里，改完重启生效：

```python
BG = "#131316"        # 面板背景
FG = "#EDEDF2"        # 时钟数字
FG_TIMER = "#FFB454"  # 定时数字
TIMER_MINUTES = 25    # 默认倒计时长度
X = None              # None = 自动贴右；也可以写 X = 1450, Y = 40 钉死位置
SOUND = True          # 到点响铃
TTS = False           # 到点用系统语音念一句
```

## 关于"置顶看不见"这件事

程序用了三层手段让自己待在最上层：Tk 的 `-topmost`、Win32 `SetWindowPos(HWND_TOPMOST)`、以及每 12 秒一次的"摘掉 topmost 再戴回去"强制重绘。

**但是**：如果某个程序跑在 **独占全屏（exclusive fullscreen）** 下，它会直接接管显示输出、绕过桌面合成器，这时**任何**普通置顶窗口都画不出来 —— 这是 Windows 的机制，不是本程序的 bug。

用 `--probe` 可以一眼判断：

```bash
python app.py --probe && type _probe.txt
```

```
设置底色=#131316
屏幕实际像素:
  (+3,+3) = (39, 41, 48)      ← ≈ 边框色，说明真的显示出来了
  (+14,+14) = (39, 41, 48)
```

如果这里读出的是游戏画面而不是窗口自己的颜色，就说明被绕过了。解决办法：把那个程序改成**窗口化 / 无边框窗口**（多数游戏 `Alt+Enter` 或设置里的"显示模式"）。想让它在全屏游戏里也能显示，只能走 DirectX 挂钩的覆盖层（RTSS 那类），不属于本项目的范围。

顺带一提，如果你机器上装着录屏/串流软件（OBS、采集卡工具等），它们自身的顶层窗口有时也会插在最上面，可以先用 `--probe` 确认排除。

## 技术说明

- **纯标准库**：`tkinter` + `ctypes`（调 Win32 API），没有任何 pip 依赖
- **无边框窗口**：`overrideredirect(True)` + 自适应内容尺寸
- **计时用 `time.monotonic()`**：不受系统时间调整影响，秒表不会漂
- **`WS_EX_TOOLWINDOW`**：不占任务栏、不出现在 Alt+Tab 里
- **等宽字体**：秒数跳动时数字宽度不变，面板不会左右抖
- **全局热键在独立线程**：`PeekMessageW` 轮询消息队列，不阻塞 Tk 主循环

已知限制：全局热键若被别的软件占用会静默失效（换 `config.py` 里的组合键即可）；多显示器下只按主屏尺寸定位。

